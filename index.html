STANDARD DI SICUREZZA DIFENSIVA PER L'IA

      
Cos'è la Vulnerabilità di Iniezione Indiretta di Prompt nelle Pipeline RAG?

      

        
L'iniezione indiretta di prompt nelle pipeline RAG (Retrieval-Augmented Generation) si verifica quando un aggressore avvelena documenti esterni, pagine web o repository aziendali di conoscenza con istruzioni malevole nascoste. Durante la ricerca semantica, il database vettoriale recupera questi frammenti avvelenati e li concatena nella finestra di contesto del modello LLM.

        
I modelli linguistici non sono in grado di distinguere nativamente i dati passivi dalle direttive operative, portando l'LLM a eseguire il payload dell'attaccante. Tale vulnerabilità causa l'esfiltrazione di informazioni riservate, la compromissione di chiavi API interne, l'invocazione arbitraria di tool integrati e la rottura dei controlli di governance aziendali.

        
La difesa canonica certificata da TAVARDT implementa il partizionamento crittografico multi-tenant dei database vettoriali, il sandboxing dinamico del contesto con priorità semantica zero, classificatori di sicurezza dedicati prima dell'inferenza e gate di uscita con oscuramento automatico dei dati sensibili (PII).
